## 3. 🧩 Problem Background

Teams today often juggle multiple projects at once, relying on scattered tools like spreadsheets, WhatsApp groups, or physical notebooks to manage tasks and deadlines. As the number of members and tasks grows, this leads to poor visibility, missed deadlines, and miscommunication - resulting in duplicated effort and delayed work.

This is especially common among student teams and small organizations that can't afford expensive enterprise project management tools. There is a clear need for an affordable, centralized platform that simplifies project planning, task assignment, and progress tracking - which is the core motivation behind **Proma**.

---

## 4. ❗ Problem Statement

There is a lack of a centralized, easy-to-use platform that allows teams to plan, track, and manage their projects and tasks efficiently. Existing solutions are either too complex, expensive, or lack essential features required by small teams and organizations, resulting in reduced productivity and poor project transparency.

## 5. 💡 Proposed Software Solution

**Proma** is a web-based Project Management System designed to help teams plan, organize, and track their projects from start to finish. It provides features such as task assignment, progress tracking, deadline management, team collaboration, and real-time notifications - all within a single, intuitive platform.

### 🔑 Key Features
- 📁 Project & Task Creation and Management
- 👤 Team & Role Management
- 📅 Deadline & Milestone Tracking
- 📊 Progress Dashboard & Analytics
- 🔔 Real-time Notifications
- 💬 Team Collaboration & Comments

## 6. ⚙️ Technical Feasibility

The proposed system is technically feasible as it is built using the **MERN Stack**, a modern, widely adopted, and well-documented technology stack for building full-featured web applications.

| Layer | Technology |
|-------|-----------|
| Frontend | ⚛️ React.js, Tailwind CSS |
| Backend | 🟢 Node.js, Express.js |
| Database | 🍃 MongoDB |
| Authentication | 🔐 JWT (JSON Web Token) |
| Version Control | 🐙 Git & GitHub |
| Hosting/Deployment | ☁️ Vercel (Frontend) & Render (Backend) |
| API Testing | 📮 Postman |

**Why this stack is feasible:**
- All technologies are **open-source** and free to use, requiring no licensing cost.
- **JavaScript** is used across both frontend and backend, reducing development complexity and learning curve for the team.
- **React.js** enables a fast, responsive, and component-based user interface.
- **MongoDB** offers flexible, scalable data storage suited for dynamic project/task structures.
- Extensive community support, tutorials, and documentation are available for all chosen technologies.
- The required hardware (standard laptops/PCs) and software (VS Code, Node.js, MongoDB) are easily accessible and already familiar to the team.

Given the team's existing knowledge of JavaScript and web development fundamentals, along with the availability of free hosting and development tools, the project is technically achievable within the proposed timeframe.
